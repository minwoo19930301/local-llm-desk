# Free AI Scheduler

각 사람 맥에서 Ollama로 로컬 모델을 받고, cron 자동화로 돌린다.

macOS와 **Python 3.10 이상**이 필요하다. Ollama가 없어도 웹 화면은 열린다. 실행기는 Python 버전이 낮으면 필요한 버전을 안내하고 종료한다.

Codex의 TOML 설정에서 연동을 자동으로 찾는 기능은 Python 3.11 이상에서 지원한다. Python 3.10에서도 다른 연동 검색과 작업 실행은 사용할 수 있다.

사람마다 HOME·경로가 다르다. crontab에 사용자 이름이나 `/Users/누구`를 넣지 않는다. `desk/cron_wrap.sh`가 자기 위치를 기준으로 실행한다.

```zsh
git clone <이 저장소>
cd local-llm-desk
./start.sh
```

1. `/` 에서 스펙을 본 뒤 `/install` 에서 프로바이더를 받고 `/install/models` 에서 모델을 받는다.
2. `/jobs` 목록에서 잡을 넣고, 지금 실행해보기 → 되면 시각을 정해 반복한다.

Ollama는 Homebrew 없이 공식 앱으로 받는다.

- http://127.0.0.1:8788/

Ollama와 모델은 맥마다 따로 받는다. 회사 공용 한 대가 아니라, 각자 맥에서 같은 도구를 돌리는 방식이다.

## Ollama는 필요할 때만 실행

- `./start.sh`와 페이지 조회는 Scheduler만 실행한다. Ollama GUI나 서버를 자동으로 열지 않는다.
- 프로바이더 설치는 앱 파일과 CLI를 준비한다. 설치가 끝난 뒤 Ollama 서버를 남기거나 로그인 항목을 등록하지 않는다.
- 작업 실행, 모델 다운로드·삭제 중에는 CLI 서버를 잠시 사용한다. 같은 서버를 쓰는 마지막 세션이 끝나면 **Desk가 시작한 서버만** 종료한다. 실패·취소·다운로드 창 연결 종료 때도 정리한다.
- 이미 사용자가 켜 놓은 Ollama는 종료하지 않는다. Desk가 쓴 모델도 다른 Desk 세션에서 쓰고 있으면 언로드하지 않는다.
- 이전 Desk 버전의 `local-llm-desk.ollama` LaunchAgent는 프로바이더 설치 시 백업 후 해제한다. 다른 서비스는 변경하지 않는다.

Ollama GUI를 직접 열면 공식 앱이 별도 로그인 항목을 등록할 수 있다. 이미 등록된 공식 앱의 자동 실행은 macOS **시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램**에서 Ollama 항목을 끌 수 있다. Desk는 GUI를 여는 경로를 사용하지 않는다.

## 실행 권한과 연동

작업에서 선택한 도구만 해당 실행의 허용 목록에 넣는다. 동시에 실행되는 작업들은 서로의 연동 매핑을 공유하지 않는다. 같은 작업의 중복 실행은 프로세스·스레드 잠금으로 막으며, 비활성 작업은 남은 cron 명령이 있어도 예약 실행하지 않는다.

macOS 외부 CLI는 `sandbox-exec`로 실행한다. 작업 폴더 권한은 `data/workspace`와 실행별 임시 폴더로 파일 접근을 제한하고, 시스템 런타임은 읽기만 허용한다. 컴퓨터 권한도 주요 자격 증명 폴더 접근을 차단한다. 다른 프로세스 제어와 로컬 서비스·IPC 접근을 제한하며 Aider/OpenCode에는 Ollama 기본 포트만 별도로 허용한다. 임시 HOME을 사용하므로 기존 CLI 로그인·설정은 자동 상속하지 않는다. Aider와 OpenCode에는 선택한 로컬 Ollama 모델을 명시한다.

`sandbox-exec`가 없으면 외부 CLI를 실행하지 않는다. `echo`, `pwd`, `ls`, `cat`, `head`, `wc`의 제한된 로컬 사용은 지원한다. 인증이 필요한 외부 서비스는 명시적으로 등록한 MCP 연동 등을 사용한다. MCP 서버는 별도 신뢰 대상이며 읽기 권한에서는 `readOnlyHint=true`로 명시된 도구만 허용한다. 웹 페이지 도구는 브라우저를 열지 않고 검증한 공개 주소의 내용을 가져온다.

## 테스트

실제 Ollama, 모델, 사용자 연동 설정이나 crontab 없이 회귀 테스트를 실행할 수 있다.

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 tests/smoke.py
```

폼 생성·수정·시험 실행과 모바일 레이아웃을 확인하려면 Node.js 22 이상과 Chrome을 설치한 뒤 실행한다. 서버 데이터는 임시 폴더를 사용하고 추론은 테스트 응답으로 대체한다.

```sh
npm ci
npm run test:browser
```

GitHub Actions는 macOS/Linux의 Python 3.10·3.13 테스트와 Chromium 브라우저 회귀 테스트를 수행한다. 실제 모델의 다운로드·추론 속도와 인증된 외부 에이전트의 전체 동작은 별도 검증이 필요하다.

### 5분 뒤 한 번 실행

작업의 `언제`에서 **5분 뒤 한 번**을 선택하거나 작업 생성 API에
`"preset": "once_5m"`을 지정한다. 저장 완료 시점부터 최소 5분 뒤의 첫 cron
분 경계에 실행하므로 실제 대기 시간은 약 5~6분이다. 실행이 끝나면 성공·실패와
관계없이 작업을 비활성화하고 cron 항목을 제거한다. 반복 일정이 아니다.

제목·프롬프트 수정이나 활성화 토글만으로 완료된 1회 예약이 다시 등록되지는 않는다.
다시 예약하려면 새 작업을 만들거나 다른 일정으로 변경한다. `지금 실행`은 예약
시각까지 기다리지 않고 즉시 실행하며, 1회 작업이면 예약도 완료 처리한다.
