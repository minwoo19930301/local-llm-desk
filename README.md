# Free AI Scheduler

각 사람 맥에서 Ollama로 로컬 모델을 받고, cron 자동화로 돌린다.

로컬 LLM을 직접 써보면 기기 성능과 모델 크기에 따라 응답이 느려, 실시간으로 대화하며 쓰기에는 기다림이 길 수 있다. 그래서 즉시 답을 받는 용도보다, 작업을 미리 예약해 두고 나중에 결과를 확인하는 스케줄러로 활용하고자 만들었다.

먼저 작업을 한 번 실행해 결과와 소요 시간을 확인한 뒤, 그에 맞춰 반복 주기를 정하는 방식이다.

사람마다 HOME·경로가 다르다. crontab에 사용자 이름이나 `/Users/누구`를 넣지 않는다. `desk/cron_wrap.sh`가 자기 위치를 기준으로 실행한다.

```zsh
git clone <이 저장소>
cd local-llm-desk
./start.sh
```

1. `/` 에서 스펙을 본 뒤 `/install` 에서 프로바이더를 받고 `/install/models` 에서 모델을 받는다.
2. `/jobs` 목록에서 잡을 넣고, 지금 실행해보기 → 되면 시각을 정해 반복한다.

Ollama는 Homebrew 없이 공식 앱으로 받는다.

- http://127.0.0.1:8788/

Ollama와 모델은 맥마다 따로 받는다. 회사 공용 한 대가 아니라, 각자 맥에서 같은 도구를 돌리는 방식이다.

## 기능별 선택과 직접 진단

작업마다 파일 읽기, CLI, 공개 HTTP/API, Chrome 주소 열기, 네이버 POP3 메일을 따로 선택한다. 기본 실행기는 이 앱의 내장 도구 루프다. Aider/OpenCode는 선택 사항이다. 화면 인식·클릭을 하는 Browser/Computer Use는 해당 MCP 서버를 연동 관리에 등록하고 작업에 선택해야 한다. Chrome 주소 열기는 로그인된 탭을 읽거나 클릭하는 기능이 아니다.

작업 작성 화면의 **모델 없이 도구 자체 확인**에서 파일·CLI·HTTP·POP3 서버 연결·메일 목록을 직접 진단한다. 모델 응답 완료는 작업 달성의 증거가 아니다. 도구 실패, 호출 JSON만 출력, 반복 한도 초과는 실패로 표시하며 호출별 성공 여부와 소요 시간을 기록한다.

## 네이버 메일 연결

기존 AGY 네이버 메일 스킬을 사용했다면 `~/.env`의 `NAVER_MAIL_USERNAME`과 `NAVER_MAIL_PASSWORD`를 자동으로 재사용한다. 파일을 실행하거나 비밀번호를 복사하지 않는다. 별도로 등록한 키체인 계정이 우선한다. 신규 연결은 `/connectors`에서 네이버 메일 주소와 애플리케이션 비밀번호를 등록한다. 네이버에서 POP3 사용과 2단계 인증을 설정해야 한다. [공식 설정 안내](https://help.naver.com/service/30029/contents/21341?lang=ko&osType=PC). 비밀번호는 macOS 키체인에 저장하고, JSON 설정에는 메일 주소만 남긴다. 키체인 접근 도구 빌드를 위해 macOS Command Line Tools가 필요하다.

연결 버튼은 모델 없이 인증과 최근 헤더 조회를 검증한다. `pop.naver.com:995`에 인증서를 검증한 TLS로 연결하며 `STAT`·`TOP`만 사용해 최근 최대 10개의 제목·보낸사람·날짜를 조회한다. 본문 다운로드(`RETR`), 삭제(`DELE`), 발송은 지원하지 않는다. POP3에 노출되는 범위는 네이버 설정에 따른다. 메일 도구를 선택한 작업에서는 조회한 헤더가 선택한 로컬 모델에 전달되고 모델 답변은 로컬 실행 기록에 남을 수 있다.
